ReCiclo Fácil — Plataforma de Coleta Seletiva

Plataforma web responsiva desenvolvida como Projeto Final da disciplina de Engenharia de Software (UNIMA — Centro Universitário de Maceió), voltada para facilitar a localização de pontos de coleta seletiva, orientar moradores e escolas sobre a separação de resíduos e permitir o registro de solicitações de coleta.

🎯 Problema que o Software Resolve

Muitas pessoas possuem materiais recicláveis em casa, mas desconhecem os pontos de entrega adequados, os tipos de resíduos aceitos em cada local ou a disponibilidade de coleta. Além disso, escolas e projetos comunitários enfrentam dificuldades para centralizar informações sobre suas ações de reciclagem. O ReCiclo Fácil reúne essas informações em um único ambiente acessível.

🛠️ Tecnologias Utilizadas

Front-end: HTML5, CSS3 (Responsivo) e JavaScript (ES6+)

Persistência de Dados: Web Storage API (localStorage)

Modelagem e Prototipação: UML (Diagramas de Casos de Uso e Classes) e Wireframes

Gestão de Projeto: Quadro Kanban (Trello / GitHub Projects)

⚙️ Principais Funcionalidades

Consulta de Pontos de Coleta (RF01): Listagem de ecopontos e escolas parceiras com endereço, horários e materiais aceitos.

Filtro por Tipo de Resíduo (RF02): Filtragem instantânea por Papel, Plástico, Vidro e Metal.

Guia Educativo de Separação (RF03): Orientações práticas sobre o que pode ser reciclado e cuidados de higienização.

Solicitação de Coleta (RF04): Formulário validado para agendamento de retirada de recicláveis com geração de protocolo.

Área Administrativa (RF05): Cadastro de novos pontos de coleta e atualização de status das solicitações (Pendente / Coletado).

🚀 Instruções de Instalação e Execução

O sistema foi projetado para ser leve e não exige instalação de dependências externas ou servidores complexos:

Clone este repositório em sua máquina:

git clone https://github.com/seu-usuario/reciclo-facil.git


Acesse a pasta do projeto:

cd reciclo-facil/src


Abra o arquivo index.html diretamente em qualquer navegador moderno (Google Chrome, Microsoft Edge, Firefox ou Safari).
